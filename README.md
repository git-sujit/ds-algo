##Backtracking
- Conceptually similar to tree traversal, at each step we fan out to move one step further to solution. If a node cannot lead to valid solution, we abandon and backtrack to parent node for other potential solution.
- Due to backtracking behavior, backtracking is faster than brute-force search
- Example: N-Queen puzzle
